# Day 03 – Introduction to CSS
**Date:** 25 June 2026

## Objective
The objective of today's session was to learn the fundamentals of CSS and understand how it is used to improve the appearance and layout of web pages.

## Topics Covered
- Introduction to CSS
- Types of CSS (Inline, Internal, External)
- CSS Selectors
- Typography properties
- Background colors
- Borders
- CSS Box Model
- Box sizing
- Display property
- Block and inline elements

## Task Assigned
No formal assignment was given during the session. I practiced the concepts independently by applying CSS to HTML pages.

## Work Done
- Applied Inline, Internal, and External CSS.
- Practiced different CSS selectors.
- Styled text using typography properties.
- Experimented with colors, borders, margins, and padding.
- Explored the CSS Box Model.
- Demonstrated block and inline elements using the display property.
- Successfully tested all programs in Visual Studio Code and a web browser.

## Learning Outcomes
- Understood the purpose of CSS in web development.
- Learned how selectors target HTML elements.
- Gained practical knowledge of spacing, typography, and layout styling.

## Conclusion
This session introduced the fundamentals of CSS and improved my ability to design visually appealing web pages.
