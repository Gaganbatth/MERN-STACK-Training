# Day 10 - Strings and String Methods

## Overview

The tenth day of the MERN Stack training focused on JavaScript Strings and the various built-in string methods used for manipulating and processing textual data. The session introduced different techniques for creating, accessing, searching, extracting, and modifying strings using JavaScript's predefined methods. Practical implementation of these methods provided a better understanding of how strings are handled in real-world applications.

---

## Topics Covered

### 1. Introduction to Strings

Studied strings as one of the primitive data types in JavaScript used to store and manipulate textual information. Also learned different ways of declaring strings using single quotes, double quotes, and template literals.

---

### 2. String Property

Learned about the commonly used string property.

**Property Covered:**

- `length`

The `length` property is used to determine the total number of characters present in a string.

---

### 3. Accessing Characters

Studied different ways to access individual characters from a string.

**Methods Covered:**

- `charAt()`
- `at()`

These methods are useful for retrieving characters at specific positions within a string.

---

### 4. Searching Methods

Learned various methods used to search for characters or substrings within a string.

**Methods Covered:**

- `indexOf()`
- `lastIndexOf()`
- `includes()`
- `startsWith()`
- `endsWith()`

These methods help determine the position or existence of text within a string.

---

### 5. Extracting Methods

Studied methods used to extract a portion of a string.

**Methods Covered:**

- `slice()`
- `substring()`
- `substr()`

These methods return a specified section of a string based on the provided indexes.

---

### 6. Modifying Strings

Explored methods used to modify and format string data.

**Methods Covered:**

- `replace()`
- `replaceAll()`
- `toUpperCase()`
- `toLowerCase()`
- `trim()`
- `trimStart()`
- `trimEnd()`
- `concat()`
- `repeat()`

These methods are commonly used to format and manipulate string values.

---

### 7. Converting Strings

Studied the method used to convert a string into an array.

**Method Covered:**

- `split()`

This method divides a string into multiple elements based on a specified separator.

---
