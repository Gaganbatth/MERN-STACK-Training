# Day 11 - Arrays and Array Methods

## Overview

The eleventh day of the MERN Stack training focused on JavaScript Arrays and the various built-in array methods used for storing, accessing, manipulating, and managing collections of data. Arrays are one of the most fundamental data structures in JavaScript, allowing multiple values to be stored in a single variable. The session covered different array operations and their practical implementation through built-in methods.

---

## Topics Covered

### 1. Introduction to Arrays

Studied arrays as a data structure used to store multiple values in a single variable. Learned how arrays help organize related data efficiently and simplify data manipulation.

**Array Declaration:**

```javascript
let fruits = ["Apple", "Mango", "Banana"];
```

---

### 2. Accessing Array Elements

Learned how to access and modify array elements using their index positions.

**Examples:**

```javascript
fruits[0]
fruits[2]
```

Also studied the `length` property used to determine the number of elements in an array.

---

### 3. Adding and Removing Elements

Explored methods used to insert and remove elements from an array.

**Methods Covered:**

- `push()`
- `pop()`
- `shift()`
- `unshift()`

These methods allow elements to be added or removed from the beginning or end of an array.

---

### 4. Array Manipulation Methods

Studied methods used to modify and combine arrays.

**Methods Covered:**

- `splice()`
- `slice()`
- `concat()`
- `reverse()`
- `sort()`

These methods help in updating, extracting, merging, and arranging array elements.

---

### 5. Searching Methods

Learned methods used to search for elements within an array.

**Methods Covered:**

- `indexOf()`
- `lastIndexOf()`
- `includes()`

These methods help determine the position or existence of an element in an array.

---

### 6. Iteration Methods

Studied methods used to traverse array elements.

**Methods Covered:**

- `forEach()`
- `map()`
- `filter()`
- `find()`

These methods simplify performing operations on every element of an array.

---

### 7. Converting Arrays

Explored methods used to convert arrays into strings.

**Methods Covered:**

- `join()`
- `toString()`

These methods generate string representations of array elements.

---
