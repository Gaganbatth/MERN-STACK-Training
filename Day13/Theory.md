# Day 13 - Document Object Model (DOM) Fundamentals

## Overview

The thirteenth day of the MERN Stack training focused on the fundamentals of the Document Object Model (DOM). The DOM represents an HTML document as a tree of objects, allowing JavaScript to access, modify, and manipulate webpage elements dynamically. The session introduced DOM selectors, content manipulation, attribute handling, and dynamic styling, which are essential concepts for creating interactive and responsive web applications.

---

## Topics Covered

### 1. Introduction to DOM

Studied the Document Object Model (DOM) and understood how JavaScript interacts with HTML elements through a structured tree-like representation of the webpage.

---

### 2. DOM Selectors

Learned different methods used to select HTML elements for manipulation.

**Selectors Covered:**

- `getElementById()`
- `getElementsByClassName()`
- `getElementsByTagName()`
- `querySelector()`
- `querySelectorAll()`

These methods enable JavaScript to locate and access specific elements within a webpage.

---

### 3. Modifying Content

Studied different properties used to update the content of HTML elements dynamically.

**Properties Covered:**

- `innerHTML`
- `innerText`
- `textContent`

These properties allow developers to change the content displayed on a webpage without reloading it.

---

### 4. Working with Attributes

Learned how to access, modify, and remove HTML attributes using JavaScript.

**Methods Covered:**

- `getAttribute()`
- `setAttribute()`
- `removeAttribute()`

These methods provide control over element attributes such as `src`, `href`, `class`, and `id`.

---

### 5. Styling Elements using JavaScript

Studied how JavaScript can dynamically apply styles and manage CSS classes.

**Concepts Covered:**

- `style` Property
- `classList`

These features help create interactive webpages by changing the appearance of elements based on user actions or application logic.

---
