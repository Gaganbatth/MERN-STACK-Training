
# Day 06 - CSS Grid Layout

## Overview

The sixth day of the MERN Stack training focused on CSS Grid Layout, a powerful two-dimensional layout system used to design complex and responsive web page structures. Unlike Flexbox, which primarily manages layouts in a single direction (row or column), CSS Grid enables developers to control both rows and columns simultaneously, making it an ideal choice for creating structured and scalable web layouts.

The session introduced the fundamentals of CSS Grid, including grid containers, grid items, grid tracks, and spacing, followed by the practical implementation of a webpage layout using Grid.

---

## Topics Covered

### 1. Introduction to CSS Grid

Studied the CSS Grid Layout Module and its significance in modern web development. CSS Grid provides a flexible and efficient way to organize webpage elements into rows and columns.

---

### 2. Grid Container

Learned how to convert an HTML element into a grid container using:

```css
display: grid;
```

The grid container acts as the parent element that controls the placement and alignment of all grid items.

---

### 3. Grid Columns and Rows

Studied the properties used to define the structure of a grid.

**Properties Covered:**

- `grid-template-columns`
- `grid-template-rows`

These properties specify the number and size of columns and rows within the grid.

---

### 4. Grid Gap

Learned how to create spacing between grid items using:

- `gap`
- `row-gap`
- `column-gap`

These properties improve the readability and appearance of grid layouts.

---

### 5. Grid Item Placement

Studied how individual grid items can be positioned within the grid using:

- `grid-column`
- `grid-row`

These properties allow elements to span multiple rows or columns and create customized layouts.

---

### 6. Building a Webpage Layout using CSS Grid

Applied the concepts of CSS Grid to design a webpage layout consisting of:

- Header
- Sidebar
- Main Content Area
- Multiple Content Sections
- Footer

This demonstrated how Grid can efficiently organize webpage components into a structured layout.
