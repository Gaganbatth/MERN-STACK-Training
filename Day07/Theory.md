# Day 07 - Introduction to JavaScript

## Overview

The seventh day of the MERN Stack training marked the beginning of JavaScript, the programming language responsible for adding logic and interactivity to web applications. Unlike HTML, which provides the structure of a webpage, and CSS, which controls its presentation, JavaScript enables developers to create dynamic and responsive web pages. The session focused on understanding the fundamentals of JavaScript, including variables, data types, and operators, which form the building blocks of programming.

---

## Topics Covered

### 1. Introduction to JavaScript

Studied JavaScript as a high-level, interpreted programming language used to create interactive and dynamic web applications. Learned about its role in front-end development and how it works alongside HTML and CSS to enhance user experience.

---

### 2. Variables

Learned how variables are used to store and manage data in JavaScript programs.

**Types of Variables Covered:**

- `var`
- `let`
- `const`

Also understood the differences between them in terms of scope, redeclaration, reassignment, and modern best practices.

---

### 3. Data Types

Studied the different data types supported by JavaScript and their significance in storing different kinds of values.

**Primitive Data Types:**

- String
- Number
- Boolean
- Undefined
- Null
- BigInt
- Symbol

**Non-Primitive Data Types:**

- Object
- Array
- Function

---

### 4. Operators

Explored the various operators used to perform operations on variables and values.

**Operators Covered:**

#### Arithmetic Operators

- `+`
- `-`
- `*`
- `/`
- `%`
- `**`

#### Assignment Operators

- `=`
- `+=`
- `-=`
- `*=`
- `/=`

#### Comparison Operators

- `==`
- `===`
- `!=`
- `!==`
- `>`
- `<`
- `>=`
- `<=`

#### Logical Operators

- `&&`
- `||`
- `!`

#### Increment and Decrement Operators

- `++`
- `--`

These operators are essential for performing calculations, comparisons, and implementing logical decision-making in JavaScript programs.
