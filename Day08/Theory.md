# Day 08 - Conditional Statements and Loops

## Overview

The eighth day of the MERN Stack training focused on understanding the decision-making and iterative capabilities of JavaScript. The session introduced Conditional Statements, which enable programs to execute different blocks of code based on specified conditions, and Loops, which allow repetitive execution of code without unnecessary duplication. These concepts are fundamental to writing efficient and logical programs.

---

## Topics Covered

### 1. Conditional Statements

Studied how JavaScript uses conditional statements to make decisions based on different conditions.

**Conditional Statements Covered:**

- `if`
- `if...else`
- `else if`
- Nested `if`
- `switch` statement

These statements help in controlling the flow of program execution based on logical conditions.

---

### 2. Loops

Learned how loops are used to execute a block of code repeatedly until a specified condition is satisfied.

**Loops Covered:**

- `for` loop
- `while` loop
- `do...while` loop

Also learned the use of loop control statements such as:

- `break`
- `continue`

These constructs simplify repetitive tasks and improve code efficiency.

---

## Task Assigned

The instructor assigned programming questions based on conditional statements and loops. The objective was to apply the concepts learned during the session by solving logical problems using different decision-making statements and looping constructs in JavaScript.
