# Day 09 - Functions and Arrow Functions

## Overview

The ninth day of the MERN Stack training focused on Functions, one of the core concepts of JavaScript that enables code reusability, modularity, and better program organization. The session covered different ways of defining functions, passing parameters, returning values, and introduced Arrow Functions, a modern and concise syntax introduced in ES6 for writing functions.

---

## Topics Covered

### 1. Introduction to Functions

Studied the concept of functions as reusable blocks of code designed to perform specific tasks. Functions help reduce code redundancy and improve readability and maintainability.

---

### 2. Function Declaration

Learned how to define functions using the `function` keyword.

**Syntax:**

```javascript
function functionName() {
    // code
}
```

---

### 3. Function Parameters and Arguments

Studied how data can be passed to functions through parameters and how arguments are supplied during function invocation.

---

### 4. Return Statement

Learned the purpose of the `return` statement, which sends a value back to the function call after execution.

---

### 5. Function Expressions

Explored functions assigned to variables and their usage in JavaScript.

**Example:**

```javascript
const greet = function() {
    console.log("Hello");
};
```

---

### 6. Arrow Functions

Studied Arrow Functions, introduced in ES6, which provide a shorter and more readable syntax for writing functions.

**Syntax:**

```javascript
const greet = () => {
    console.log("Hello");
};
```

Also learned the basic differences between traditional functions and arrow functions.
