# Day 02 - HTML Forms

## Overview

The second day of the MERN Stack training focused on HTML Forms, one of the most essential components of web development. HTML forms provide an efficient mechanism for collecting user input and facilitating interaction between users and web applications. During the session, various form elements, input types, and attributes were explored to understand how data is captured, validated, and submitted.

The concepts covered during the session established a strong foundation for designing interactive web pages and implementing user-friendly forms.

---

## Topics Covered

### 1. Introduction to HTML Forms

Studied the purpose and structure of HTML forms. The `<form>` element acts as a container that groups various input controls used to collect user information.

---

### 2. Form Elements

Explored commonly used form elements, including:

- `<form>`
- `<label>`
- `<input>`
- `<textarea>`
- `<select>`
- `<option>`
- `<button>`

---

### 3. Input Types

Studied different input types available in HTML.

**Examples**

- text
- password
- email
- number
- date
- radio
- checkbox
- file
- submit
- reset

Each input type is designed to collect a specific kind of user data.

---

### 4. Form Attributes

Learned the purpose and usage of commonly used form attributes.

**Attributes Covered**

- id
- name
- placeholder
- required
- readonly
- disabled
- maxlength
- min
- max

These attributes enhance functionality, improve user experience, and support input validation.

---

### 5. Dropdown Lists

Studied the implementation of dropdown menus using the `<select>` and `<option>` elements, allowing users to select one option from multiple predefined choices.

---

### 6. Text Area

Learned the use of the `<textarea>` element for collecting multi-line user input, such as comments, suggestions, and feedback.

---

### 7. Buttons

Implemented different button types including:

- Submit Button
- Reset Button
- Normal Button

These buttons are used to perform various actions within a form.
